# API Contract (Frontend Mock Boundary)

The app is still frontend-only. These endpoints document the future HTTP shape; today they are implemented by `src/api/mockApiClient.ts` against local mock data.

| Method | Endpoint                   | Purpose                                  | Request                                                 | Response                      | Current mock equivalent                                   | Future backend notes                                                  |
| ------ | -------------------------- | ---------------------------------------- | ------------------------------------------------------- | ----------------------------- | --------------------------------------------------------- | --------------------------------------------------------------------- |
| GET    | `/api/tasks`               | List board tasks.                        | None                                                    | `TaskDto[]`                   | `listTasks()` clones seeded mock tasks.                   | Add auth scoping, pagination, and server-side filtering if needed.    |
| POST   | `/api/tasks`               | Create a task.                           | `CreateTaskRequestDto`                                  | `TaskDto`                     | `createTask()` appends to the in-memory mock store.       | Validate status transitions and required fields server-side.          |
| PATCH  | `/api/tasks/{id}`          | Update task metadata.                    | `UpdateTaskRequestDto` without `id` in the body         | `TaskDto`                     | `updateTask()` patches a mock task.                       | Return typed 404 errors for unknown tasks.                            |
| POST   | `/api/tasks/{id}/move`     | Move a task to another board status.     | `{ "status": TaskStatusDto }`                           | `TaskDto`                     | `moveTask()` updates mock task status.                    | Enforce workflow transition rules and emit audit events.              |
| GET    | `/api/activity-events`     | List activity feed events.               | None                                                    | `ActivityEventDto[]`          | `listActivityEvents()` clones seeded mock events.         | Add cursor pagination for long streams.                               |
| POST   | `/api/activity-events`     | Append an activity event.                | `CreateActivityEventRequestDto`                         | `ActivityEventDto`            | `createActivityEvent()` prepends to the mock feed.        | Backend may derive some events automatically from domain actions.     |
| GET    | `/api/workflow/nodes`      | List workflow nodes.                     | None                                                    | `WorkflowNodeDto[]`           | `listWorkflowNodes()` clones seeded mock nodes.           | Version workflows and scope by project/workspace.                     |
| GET    | `/api/workflow/edges`      | List workflow edges.                     | None                                                    | `WorkflowEdgeDto[]`           | `listWorkflowEdges()` clones seeded mock edges.           | Validate that referenced nodes exist.                                 |
| PATCH  | `/api/workflow/nodes/{id}` | Update node position/configuration.      | `UpdateWorkflowNodeRequestDto` without `id` in the body | `WorkflowNodeDto`             | `updateWorkflowNode()` patches mock node position/config. | Persist editor coordinates and validate config schemas per node type. |
| POST   | `/api/workflow/validate`   | Validate the workflow graph.             | None                                                    | `WorkflowValidationResultDto` | `validateWorkflow()` checks for start/end nodes.          | Add DAG, reachability, and transition validation.                     |
| POST   | `/api/workflow/simulate`   | Run a dry-run simulation.                | None                                                    | `WorkflowSimulationResultDto` | `simulateWorkflow()` returns canned log output.           | Execute deterministic simulation without invoking real agents.        |
| POST   | `/api/workflow/publish`    | Publish the current workflow definition. | None                                                    | `PublishWorkflowResultDto`    | `publishWorkflow()` returns a mock version string.        | Create immutable versions and deployment audit records.               |

DTO definitions live in `src/api/dto.ts`. UI/domain models remain in `src/types` and are bridged through `src/api/mappers.ts`.
